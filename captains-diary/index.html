Built-in onboarding

The demo is your manual.

The app comes with a writable example Markdown project. One root, three chapters and three nested rooms per chapter. Read the docs in the very editor they explain.

  1. Explore. Navigate the tree, view a folder as one document, then open the Knowledge Graph.
  2. Write. Edit the tutorial sandbox, save a sentence, inspect the Timeline event and Diff.
  3. Deliver. Learn the local-first workflow, open your own project and understand alpha limitations.
